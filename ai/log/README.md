# Registro de intervenciones de IA

Un archivo por intervención material de IA, con identificador
`IA-AAAA-MM-DD-NN` (correlativo por día) y el formato de
[`templates/registro-ia.md`](../../templates/registro-ia.md). Véase
[`ai/policy.md`](../policy.md) para qué usos requieren registro y
[`.claude/rules/ai-transparency.md`](../../.claude/rules/ai-transparency.md)
para las reglas que rigen este directorio.
