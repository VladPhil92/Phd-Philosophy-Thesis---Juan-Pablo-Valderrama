# Reglas de acceso de IA a la biblioteca

No se envían originales protegidos, datos privados, OCR ni transcripciones a un
sistema externo sin autorización expresa y base jurídica. La IA puede ayudar a
ordenar metadatos permitidos, pero su salida no es evidencia. Toda cita,
atribución o referencia propuesta por IA permanece **no verificada** hasta el
cotejo humano con una fuente autoritativa; el uso material se registra mediante
[`../templates/registro-ia.md`](../templates/registro-ia.md).
