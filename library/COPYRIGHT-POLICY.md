# Política de copyright y fuentes privadas

Git contiene metadatos, notas propias y fragmentos solo cuando su inclusión es
lícita. No se versionan libros, escaneos, originales, OCR íntegro,
transcripciones privadas ni bases locales. El acceso legítimo no equivale a
permiso de redistribución. Ante duda, se conserva únicamente la referencia con
`TODO — VERIFY` y se consulta la normativa institucional y aplicable.
