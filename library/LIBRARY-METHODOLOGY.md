# Metodología de la biblioteca

La biblioteca separa el original autorizado, el derivado mecánico, la evidencia
verificada y la interpretación. El ID `LIB-AUTOR-NNN` no cambia aunque cambien
los metadatos. Ninguna entrada con `TODO — VERIFY` puede alimentar una cita.

Cadena mínima: `LIB-* → nota de lectura → cita verificada → ARG-* → capítulo`.
Una transcripción u OCR facilita búsqueda, pero no es evidencia. La comparación
con el ejemplar autorizado, el localizador y la identidad de quien verifica son
obligatorios. La nota del investigador debe distinguirse de todo análisis
asistido por IA.
