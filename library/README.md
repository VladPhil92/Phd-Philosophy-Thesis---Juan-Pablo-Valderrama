# Biblioteca doctoral

Esta capa versiona **únicamente metadatos, estados de verificación y registros de
procedencia**. Los originales, OCR y transcripciones privadas permanecen fuera
de Git conforme a [la política de copyright](COPYRIGHT-POLICY.md).

Los 28 registros provisionales del corpus se enumeran en
[`library-index.md`](library-index.md). Un registro no acredita posesión, lectura
ni verificación de una obra. `TODO — VERIFY` indica que el dato debe comprobarse
contra una fuente autorizada antes de emplearlo.

## Flujo

1. crear el registro con un ID estable;
2. comprobar metadatos y situación bibliográfica;
3. conservar el original lícito solo en almacenamiento privado;
4. producir OCR/transcripción privada cuando sea legal;
5. cotejar cada cita con el original y registrar el localizador;
6. trasladar únicamente evidencia verificada a una nota y, después, a un
   argumento y capítulo.

Véanse los [protocolos](LIBRARY-METHODOLOGY.md) y las [plantillas](templates/README.md).
