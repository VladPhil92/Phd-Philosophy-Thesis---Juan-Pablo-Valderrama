# Protocolo de verificación de fuentes

Para verificar una cita se comprueban identidad de la edición, autoría, texto,
localizador, contexto, traducción y derechos de uso. Se registra fecha y persona
responsable. Catálogos, OCR, notas secundarias y salidas de IA no sustituyen el
original autoritativo. Las discrepancias permanecen abiertas y explícitas.
