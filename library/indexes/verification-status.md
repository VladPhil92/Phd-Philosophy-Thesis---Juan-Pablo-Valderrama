# Verification Status Index

Allowed transcription statuses: `OCR_RAW`, `OCR_CLEANED`, `PARTIALLY_VERIFIED`, `TERMINOLOGY_VERIFIED`, `FULLY_VERIFIED`, `SOURCE_LOCKED`. Report scope with every status.

AI finding statuses: `LOCATED`, `TRANSCRIPTION_MATCH`, `SOURCE_VERIFIED`, `INTERPRETATION_PENDING`, `INTERPRETATION_APPROVED`. These do not substitute for transcription status.
