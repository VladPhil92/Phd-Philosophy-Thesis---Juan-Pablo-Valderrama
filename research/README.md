# Diseño de investigación

Contiene el planteamiento, las preguntas, el marco conceptual y la metodología.
Las decisiones metodológicas deben indicar fecha, justificación y consecuencias
para el corpus o el análisis.

`questions.md` es la autoridad para preguntas `PI-*` y `concept-registry.md`
para navegación conceptual. Las exposiciones del README no los redefinen.
