# Registro de argumentos

Este directorio conserva una ficha por argumento mediante identificadores
`ARG-*`. Cada ficha debe enlazar las preguntas pertinentes, las fuentes
verificadas, las objeciones, los límites y el lugar previsto en la tesis. Use
[`../../templates/ficha-argumento.md`](../../templates/ficha-argumento.md).
`research/argument-map.md` es únicamente una vista de relaciones entre estas
fichas y nunca redefine su contenido o estado.
