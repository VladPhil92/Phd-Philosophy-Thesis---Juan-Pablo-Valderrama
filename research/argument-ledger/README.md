# Registro de argumentos

Cada argumento doctoral debe tener un archivo propio creado desde `templates/argument-record.md`. El identificador sigue `ARG-CH<capítulo>-<número>` (por ejemplo, `ARG-CH5-003`) y no se reutiliza aunque el argumento se retire.

Un registro enlaza las fuentes y notas de las que parte, distingue la interpretación del investigador, explicita la inferencia, enfrenta una objeción y señala el capítulo de destino. Si intervino IA, enlaza la interacción y su verificación; marcar `used: false` o dejar la lista vacía no exime de documentar el resto de la cadena.

## Regla de promoción

Solo un argumento con fuentes y citas comprobadas, lectura primaria pertinente, objeción atendida y aprobación humana puede pasar de `active` a `accepted` e integrarse en un capítulo.
