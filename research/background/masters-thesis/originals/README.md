# Original archivístico

Aquí se conserva una copia autorizada del PDF histórico, identificada por hash
en [`../metadata.md`](../metadata.md). El documento de 2020 **no representa la posición
doctoral actual** y se preservará sin corregir redacción, citas, argumentos o
conclusiones; las críticas viven fuera del PDF.

Para sustituir la copia: confirmar autorización; registrar nombre, tamaño,
páginas, procedencia y acceso público; calcular `sha256sum` sobre el archivo
real; y crear un registro nuevo si cambia un byte, sin sobrescribirlo.
Los campos están en [`../metadata.md`](../metadata.md). Un hash identifica una
copia, pero no certifica por sí solo autoridad textual.
