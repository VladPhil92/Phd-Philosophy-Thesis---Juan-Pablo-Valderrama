# Concept registry

This file is the canonical **index** of doctoral concepts. It does not duplicate
definitions, analyses, or arguments: each future entry must point to the source
note or argument record where the substantive treatment and evidence live.

| Concept ID | Label | Canonical analysis | Related arguments | Status |
|---|---|---|---|---|

An empty index is preferable to speculative concepts. Add an entry only after a
canonical analysis exists elsewhere in the repository.
