# Plantillas

Formatos reutilizables para documentar fuentes, argumentos y usos relevantes de
inteligencia artificial. Los marcadores deben sustituirse con información
verificada; una plantilla no constituye evidencia.

`checklist-fase.md`, `revision-semanal.md`, `revision-mensual.md` y
`revision-trimestral.md` son plantillas ejecutivas de seguimiento del
[`MASTER_EXECUTION_PLAN.md`](../MASTER_EXECUTION_PLAN.md); su uso no es
obligatorio por calendario.
